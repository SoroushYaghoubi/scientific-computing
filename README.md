# uni-implementations

Things I found cool enough during my CS degree to implement myself.


## formal-languages (Odin)
- `beta-reducer.odin` — parser + β-reduction for the untyped λ-calculus
- `stack_machine.odin` — a small concatenative stack language
  (Forth-style), with `checkpoint`/`runbackif` as its only control flow

## automata-theory (Java) — WIP
DFAs, transition functions, and context-free grammars with parse
trees — built while taking GTI. Unfinished; DFA simulation works,
CFG parsing is partial.

## misc.
Grab bag: axial coordinate arithmetic for hex grids (Kotlin, extracted
from a uni game project), Horn-SAT solver, polynomial interpolation,
interval nesting, a queue.

No frameworks, no dependencies — the point was always the algorithm. Will
add more things here later.
